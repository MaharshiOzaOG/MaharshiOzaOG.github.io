Trailer Coupler Height Estimation with a Monocular Fisheye Camera

Magna Electronics
C++PythonOpenCV

Problem

Automated trailer hitching needs to know how high the trailer coupler sits, but a production vehicle only has one rear fisheye camera and no depth sensor.

What I did

  • Undistorted fisheye frames to a rectilinear (pinhole) model using the camera's intrinsic parameters.
  • Detected and matched features between frames captured as the vehicle moved, using OpenCV feature-matching algorithms.
  • Estimated the relative camera geometry with the 8-point algorithm inside RANSAC to reject outlier matches.
  • Triangulated the matched points to reconstruct 3D points and recover the coupler height.
