Stride Value Predictor for a RISC-V Out-of-Order Simulator

NC State · Advanced Microprocessor Architecture
C++

Problem

Break data dependencies in an out-of-order core by predicting instruction results.

What I did

  • Developed a cycle-accurate RISC-V out-of-order simulator.
  • Integrated a Stride Value Predictor with VPQ and checkpoint recovery.
  • Added a Global Stride History Table with LRU replacement within a 27 KB storage budget.

Result

Harmonic-mean IPC improved from 1.91 to 2.00 across 15 benchmarks.
