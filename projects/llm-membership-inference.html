Membership-Inference Attack on LLMs via Hardware Performance Counters

NC State · Team project
PythonPyTorchHugging FaceLinux perfscikit-learn

Problem

Can hardware-level side information during inference leak which data an LLM was fine-tuned on?

What I did

  • Fine-tuned GPT-2 Medium on a Books3 subset to create known member and non-member text sets (my part).
  • Implemented hardware performance counter collection during CPU inference: cycles, instructions, LLC load misses, dTLB load misses and stall cycles (my part).
  • With the team, trained a random-forest classifier on the counter data and analyzed feature importance.

Result

The classifier separated training-set members from non-members with 73% accuracy and 0.827 ROC-AUC.
