Scan Insertion and ATPG Setup: 8-bit Counter

Cadence DFT Fundamentals labs
GenusModusVerilogIcarus Verilog

Problem

A tester can only drive primary inputs and watch primary outputs, so flip-flop state is hard to set and observe. Scan makes every register directly controllable and observable.

What I did

  • Inserted mux-D scan in Cadence Genus (45 nm GPDK): set the scan style and shift-enable, ran DFT rule checks (all 8 flops scannable) and auto-stitched one chain (scan_in → 8 flops → scan_out).
  • Generated the scan netlist, SDC, SDF and SCANDEF, plus the Modus ATPG handoff: pin-assign file, test mode and ATPG scripts.
  • Wrote behavioural models of the 9 library cells the netlist uses, so the licensed netlist could be simulated with open-source Icarus Verilog.
  • Verified the gate-level scan netlist with a self-checking testbench running load → capture → unload scan patterns: reset, functional counting, scan load of A5, capture to A6, unload on scan_out, and FF → 00 wrap.

Result

All 6 gate-level scan checks passed. ATPG was set up but not run, so no fault coverage is claimed.
