Microarchitecture Reverse Engineering of Modern x86 Processors

NC State · Microarchitecture Reverse Engineering (with a teammate)
Cx86 / AVX2 / AMXMicrobenchmarkingPython

Problem

Vendors don't publish most microarchitectural details, so they have to be measured from software on real hardware.

What I did

  • Wrote C microbenchmarks to enumerate the cache hierarchy, measure cache line size, L1/L2 miss latencies and LLC inclusivity.
  • Reverse-engineered the TLB hierarchy and page-walk behavior, and measured the cost of a TLB miss.
  • Characterized branch target buffer capacity, associativity and contention, and estimated pipeline depth and reorder buffer size.
  • Measured AVX2 instruction latency and throughput, and studied how AMX BF16 matrix operations behave as input sparsity changes.
  • Ran experiments on two different Intel server machines and compared the results.
