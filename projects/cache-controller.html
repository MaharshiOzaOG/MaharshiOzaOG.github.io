Design Verification

Set-Associative Write-Back Cache Controller – RTL and UVM

Personal project
SystemVerilogUVMSVAPython

Problem

Design a realistic cache controller and verify it the way an industry DV team would.

What I did

  • Designed an N-way set-associative write-back/write-allocate blocking cache with selectable LRU/LFU replacement, dirty tracking, a flush/invalidate engine and valid/ready interfaces.
  • Partitioned it into tag-compare, replacement, dirty-tracking and single-port SRAM modules under a central FSM, with a bound SVA checker.
  • Built a UVM environment with CPU, flush and reactive-memory agents and a reference-model scoreboard.
  • Wrote 7 directed and constrained-random tests (backpressure, flush/CPU races, memory error injection) and a Python regression flow that merges coverage.

Result

0 data mismatches across 1,000+ accesses under injected errors.
